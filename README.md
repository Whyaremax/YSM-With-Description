# YSM With Description

This repository is a descriptive fork/reference collection based on the YSM model repository by Elaina69:

- https://github.com/Elaina69/Yes-Steve-Model-Repo/

The goal of this repository is to make the included models easier to understand by adding descriptions, usage notes, and basic organization.

> Model files, textures, animations, archives, screenshots, names, and other third-party assets belong to their original creators, uploaders, or rights holders. This repository does not claim ownership of those assets.

> [!WARNING]
> The Yes Steve Model mod is free. If a website or person asks you to pay for the mod or for models that were originally shared for free, be careful and avoid it.

## What are these files?

The files are usually `.zip` archives or `.ysm` files. They contain player models and related JSON/config data used by the Yes Steve Model mod to render custom player models in Minecraft.

## How to install a model

1. Open Minecraft with Yes Steve Model installed.
2. Open your world.
3. Go to the controls menu and find the Yes Steve Model keybind.
4. Press the model menu hotkey. For many setups, this is `Alt+Y`.

![Avatar GUI Location](https://github.com/user-attachments/assets/5f37744a-943f-4252-b03b-8cab56a02b11)

You should see the model selection screen:

![image](https://github.com/user-attachments/assets/4ea20b87-1c2d-4b54-a080-e9541593f737)

Click the folder button in the upper-right area of the model screen. If you do not see this button, make sure you are using a recent version of Yes Steve Model from Modrinth:

- https://modrinth.com/mod/yes-steve-model

Then click **Open Model Folder**.

![image](https://github.com/user-attachments/assets/911b61d0-91ba-451a-a750-9d17ee0197b2)

The model folder is usually located here on Windows:

```text
%appdata%\.minecraft\config\yes_steve_model\custom
```

Download a model from this repository or from the original model repository, then place it in that folder. After that, select the model from the in-game model screen.

## Do I need to restart Minecraft?

Usually, no. If Minecraft was already open when you installed the model, leave and rejoin the world, then open the model menu again. The new model should appear.

## Multiple models inside one file

Some creators include multiple model variants inside one model package.

![image](https://github.com/user-attachments/assets/6a7fb03c-95eb-46b7-b583-0d187dffbde5)

To check variants, click the shirt-like button in the model screen:

![image](https://github.com/user-attachments/assets/b2f67ccf-ac83-4fe0-83b4-10d38c010e7e)

You should then be able to see the available animations and model variants.

## Removing a model

To remove a model, delete it from the custom model folder and reload the model list in game.
